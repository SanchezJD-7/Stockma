# Stockma — Frontend web

Cliente web de Stockma. React 19 + TypeScript + Vite + Tailwind CSS 4,
con TanStack Query para datos del servidor y Zustand para estado de UI.

## Comandos

| Comando                | Qué hace                                                 |
| ---------------------- | -------------------------------------------------------- |
| `npm run dev`          | Servidor de desarrollo (proxy `/api` → `localhost:5000`) |
| `npm run build`        | Build de producción                                      |
| `npm run typecheck`    | Chequeo de tipos sin emitir                              |
| `npm run lint`         | oxlint                                                   |
| `npm run test`         | vitest                                                   |
| `npm run format:check` | Verifica formato con Prettier                            |

La organización por features llega en la Fase 6 del slice `inventory-foundation`.
